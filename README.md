# OIBSIP – Web Development & Designing

Welcome to my Oasis Infobyte Internship Projects Repository!

This repository showcases the projects developed as part of my **Oasis Infobyte Internship Program** under the **Web Development & Designing – Level 2** track.

## Projects

### 1. Advanced Calculator
A modern, browser-based calculator designed to perform basic arithmetic and scientific calculations with an interactive user interface.

**Technologies:** HTML5, CSS3, JavaScript

### 2. Srinivasa Ramanujan – Tribute Page
A responsive tribute website celebrating the life, achievements and mathematical contributions of Srinivasa Ramanujan, famously known as *The Man Who Knew Infinity*.

**Technologies:** HTML5, CSS3, JavaScript

### 3. Bloom – To-Do Web App
A motivational productivity and personal growth dashboard featuring task management, daily habits, progress tracking, a focus timer and inspirational affirmations.

**Technologies:** HTML5, CSS3, Vanilla JavaScript, Local Storage

### 4. Forma – Login Authentication System
A modern authentication system featuring user registration, login validation, password hashing and a protected dashboard with session management.

**Technologies:** HTML5, CSS3, JavaScript, Web Crypto API, Local Storage, Session Storage

## Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla)
- Browser Local Storage
- Session Storage
- Web Crypto API
