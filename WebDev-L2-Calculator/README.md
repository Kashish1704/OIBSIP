# Advanced Calculator

A responsive, browser-based scientific calculator. No installation or build step is required.

## Run
1. Extract `advanced_calculator.zip`.
2. Open `index.html` in a modern browser.

## Features
- Basic arithmetic, brackets, percentages and powers
- Scientific functions: sin, cos, tan, square root, log, ln and factorial
- DEG/RAD angle modes, π and e constants
- Memory keys: MC, MR, M+, M− and MS
- Ans, square, reciprocal and sign toggle
- Calculation preview, clickable history and clear-history action
- Keyboard input, responsive layout and light/dark theme

## Keyboard
Numbers and operators work directly. Press `Enter` to calculate, `Backspace` to delete, and `Escape` to clear.

The calculator evaluates a restricted mathematical expression grammar in the browser. Avoid entering untrusted code into the expression field.
