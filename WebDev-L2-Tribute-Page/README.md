# Srinivasa Ramanujan — The Man Who Knew Infinity

A responsive tribute page celebrating the life and mathematical legacy of Srinivasa Ramanujan.

## Run locally
1. Keep `index.html`, `style.css`, and `script.js` in the same folder.
2. Open `index.html` in a modern browser.
3. An internet connection is required for the portrait image and Google Fonts.

## Built with
- HTML5
- CSS3
- Vanilla JavaScript
