**# Bloom — Grow Every Day 🌸**

Bloom is a responsive, motivational to-do and personal growth dashboard built with HTML, CSS and vanilla JavaScript.

**## Features**
\- Add, edit, delete, search and complete tasks
\- Due dates, priority levels and task views (All, Today, Upcoming, Completed)
\- Daily progress tracker with animated progress bar
\- Growth streak based on days when at least one task is completed
\- Editable Dream Board saved in the browser
\- Daily habit check-ins (water, reading and movement)
\- Focus timer with start, pause and reset controls
\- Rotating affirmations, completion celebrations and confetti
\- Local storage keeps tasks and preferences in the browser
\- Responsive layout and animated interface

**## Run locally**
1\. Download and extract the ZIP.
2\. Open \`index.html\` in a modern browser.
3\. Add your first task and start growing!

**## Technologies**
\- HTML5
\- CSS3 (responsive layout, gradients, transitions and keyframe animations)
\- JavaScript (DOM events, dialogs and localStorage)

\> This is a front-end productivity project. Data is stored locally in the browser and is not synced between devices.
